# KIRKTUBE

> *MAKING SIMPLE THINGS UNNECESSARILY DIFFICULT SINCE FOREVER.*
> — KIRKTUBE CORP™

A DELIBERATELY CURSED, BUGGY VIDEO PLAYER THAT STARTS OUT LOOKING LIKE A MODERN STREAMING APP AND SLOWLY TURNS INTO A CHAOTIC RPG RUN BY THREE RIVAL AI CHARACTERS: **MAIMAI** (`meimei.png`), **VERITY** (`verity.png`), AND **EINSTEIN** (`Einstein.png`).

**RESTRICTION:** ALL TEXT AND COMMENTS ACROSS THE ENTIRE APPLICATION ARE STRICTLY UPPERCASE.

**STATUS:** PHASE 1 (FOUNDATION) DONE. THIS README GETS FINISHED IN PHASE 9.

## RUNNING IT

IT'S A STATIC SITE WITH NO BUILD STEP AND NO BACKEND.

```powershell
cd kirktube
python -m http.server 8000
```

THEN OPEN **HTTP://LOCALHOST:8000** IN GOOGLE CHROME.

## ADDING YOUR VIDEO

PUT AN MP4 AT `assets/demo-placeholder.mp4`, THEN RELOAD THE PAGE OR CLICK **RETRY** ON THE PLACEHOLDER SCREEN.
